RedisPipeline

add

defn

(Fn [(Ref RedisPipeline a), String, (Ref (Array RESP) b)] ()) 

                        (add p cmd args)

adds a command to the pipeline.

The command name must use spaces to separate sub-commands (e.g. @"CLIENT ID", not @"client-id"). The with-pipeline macro converts hyphens to spaces automatically, but add does not.
